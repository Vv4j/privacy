# AGENTS.md

Project map for AI agents working in this repository.

## Stack

Two static HTML pages served by GitHub Pages from the root of `main`. No build step.

## Structure

- `index.html`: home page URL for the Google OAuth app's Branding page.
- `privacy.html`: privacy policy URL for the same page.

## Conventions

- This repo is public. Never add names, emails, account IDs, client IDs, or local paths.
- The pages must stay reachable at the URLs listed on the OAuth Branding page; renaming a file
  breaks the published app's branding.
