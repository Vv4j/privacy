Privacy policy

Last updated: 2026-10-24

This Google OAuth app is used by one person, its owner, to let their own command-line tools work with their own Google account. It has no other users.

Data the app accesses

With the owner's consent, the app reads and edits the owner's Google Docs, Sheets, and Drive files through Google's APIs.

One of the owner's tools also asks for Gmail, Calendar, and Apps Script permissions. Those APIs are turned off for this app, so it cannot use that access.

How the data is used and stored

Data is used only to carry out the owner's own requests on the owner's own computer. Access tokens are stored locally in the computer's keychain. No data is sent to any server run by the app, sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from the Google Account's Third-party connections page.
